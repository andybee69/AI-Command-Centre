# AI Command Centre

AGON AI tools, workflows and experiments.

## Start here

Double-click **START COMMAND CENTRE.cmd** in the repository root.

That starts:
- Chippy dashboard: http://127.0.0.1:8766
- Ops Room: http://127.0.0.1:8767

Inside Chippy:
- Home / Projects / To-Do = project status and next actions.
- GIGI / Inbox = capture and assess learning links.
- System = health check for Chippy, AGON_BRAIN, GIGI, Ops Room and local Ollama.
- Chippy Chat = prepares a handoff message for the main Chippy conversation.

## Recovery

If anything stops, use `docs/recovery.md`. The recovery build was completed
as T1-T5 on 1 October 2026 and the repository was left clean and pushed.

## Sources of truth

- GitHub = code and build history.
- AGON_BRAIN = business/project knowledge.
- GIGI records remain in AGON_BRAIN.
- Ops Room / GitHub issues = build coordination.
