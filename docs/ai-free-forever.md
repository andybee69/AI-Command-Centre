# AI Free Forever integration

Purpose: free overflow / utility AI for non-sensitive work.

## Use it for
- public-web research prompts
- generic writing or rewriting
- coding snippets with no secrets
- image prompt experiments
- translation and brainstorming
- cross-checking an answer from another model

## Never send
- customer names/lists
- AGON pricing, margins or quotes
- certificates or serial/job data
- credentials, API keys or passwords
- confidential supplier/customer documents
- personal data

## Operating rule
AI Free Forever's published Terms prohibit automated/bot access. The Command Centre therefore opens the service for manual use and may copy a prompt to the clipboard, but it must not auto-submit, scrape, or drive the site.

## Launcher
Double-click `Open AI Free Forever.cmd`.

PowerShell:
`scripts\Open-AI-Free-Forever.ps1 -Page models`

With a safe prompt copied automatically:
`scripts\Open-AI-Free-Forever.ps1 -Page chat -Prompt "Compare three public approaches to this problem."`

## Routing
Use local Ollama first for private AGON material.
Use ChatGPT/Claude/other approved connected tools for richer work.
Use AI Free Forever as a free second opinion, overflow route, or creative/model comparison tool.
