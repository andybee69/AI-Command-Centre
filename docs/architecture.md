# AI Command Centre Architecture

This repository holds code, prompts, skills and workflow notes for the AI Command Centre.

## Main areas

- apps = small tools and dashboards
- docs = architecture and project notes
- prompts = reusable prompts
- scripts = PowerShell and Python automation
- skills = approved Claude/OpenCode skills

## Rule

GitHub is for code, prompts and technical workflow files.
Business documents stay in OneDrive.
